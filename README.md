# MOOD

Turn a photo into a feeling.

MOOD is an AI-assisted photo editor that translates natural-language
requests into understandable image adjustments, with a before-and-after
preview and iterative refinement.

## Status

Early hackathon development.

## Run locally

1. Create and activate a Python virtual environment.
2. Install dependencies:

   ```powershell
   python -m pip install -r requirements.txt
   ```

3. Start the app:

   ```powershell
   python app.py
   ```

## Configuration

Copy `.env.example` to `.env` if the selected AI provider requires credentials.
Never commit real API keys or private photos.
